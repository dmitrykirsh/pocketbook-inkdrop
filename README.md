# InkDrop

Передача книг и изображений на PocketBook Verse PB629 по Wi-Fi с Android, iPhone или компьютера. Откройте InkDrop на ридере, отсканируйте QR-код и выберите файлы в браузере. Файлы сохраняются в папку `Downloads`.

## Установка

Скачайте [InkDrop-PB629.zip](release/InkDrop-PB629.zip), распакуйте его и следуйте короткой инструкции `Установка.txt`. Приложение проверено на PocketBook Verse PB629; совместимость с другими моделями не проверялась.

Поддерживаются EPUB, FB2, PDF, DJVU, DOC/DOCX, RTF, TXT, HTML, CHM, CBR/CBZ и изображения JPG, PNG, BMP, TIFF. Ограничение размера файла — 500 МБ. Файлы не преобразуются, их открытие зависит от возможностей ридера.

Телефон и ридер должны быть в одной Wi-Fi-сети. Передача происходит напрямую, без облака. Соединение HTTP не шифруется: используйте доверенную сеть. Сервер работает, пока открыт InkDrop.

## Исходники и сборка

Код ридера находится в `book/src`, лаунчер — в `book/applications`. Для кросс-сборки необходимы ARMv7 toolchain Bootlin и библиотеки соответствующей прошивки ридера; они не входят в репозиторий. `book/build.sh` собирает бинарники в контейнере с toolchain в `/tc`; после сборки нужен `book/patch.ps1`, как и в проекте PageTurn. Исходный QR-кодер заимствован из PageTurn (MIT). Заголовок InkView — из публичного PocketBook SDK.

Проект не связан с PocketBook.
